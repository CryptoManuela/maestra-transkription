# 🎙️ Maestra Transkription — deine eigene App

Verwandle Audio & Video in Text — in Sekunden. Deine eigene, installierbare
Transkriptions-App mit fest hinterlegtem Zugang. Kein technisches Vorwissen nötig.

## In 3 Schritten zu deiner App

**1. fal.ai-Key holen** (einmalig, ~5 Min)
Konto auf [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) anlegen,
Zahlungsmethode hinterlegen, einen Key erstellen und kopieren
(Format: `KEY_ID:KEY_SECRET`). → Bebilderte Anleitung: siehe `ANLEITUNG.md`.

**2. Deine App erstellen** — auf den Button klicken:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/CryptoManuela/maestra-transkription)

Netlify führt dich durch: GitHub verbinden → **deinen fal.ai-Key einfügen**,
wenn nach `FAL_KEY` gefragt wird → „Deploy". Fertig — du bekommst deine eigene
Web-Adresse.

**3. Als App speichern**
Deine Adresse öffnen → am Handy „Zum Home-Bildschirm", am Laptop „Installieren".
Eigenes App-Icon, öffnet wie eine normale App.

## Ab dann
App öffnen → Datei reinziehen → Transkript. **Nie wieder einen Key eingeben,
nichts einzustellen.**

- Bis 90 MB Einzel-Upload, größere Dateien werden automatisch in Teile zerlegt.
- Modell **Wizper** = blitzschnell. **Whisper** = mit Speaker-Trennung
  („Sprecher 1 / Sprecher 2").
- Kosten: ~1 Cent pro Stunde Audio über deinen fal.ai-Account.
